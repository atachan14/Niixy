
# Community Vision

## 概要

継続的な人間関係や、小規模・内輪的なコミュニケーションを形成するための機能。

情報を広く発信することだけではなく、小さな Community 内で継続的に交流する体験を重視する。

---

## 想定機能

* Community の作成
* Community への参加
* メンバー管理
* Community ごとの掲示板
* Community 独自の Interface 定義
* Interface の実装を参加条件として設定
* Interface 情報を利用した Community 内コミュニケーション

---

## Event との関係

Event と Community は独立した主要機能として扱う。

一方で、例えば以下のような連携を将来的に検討する。

1. Map から Event を発見する
2. Event に参加する
3. Event を主催する Community を発見する
4. Community に参加する
5. Event 終了後も Community 内で交流する

具体的な連携仕様については未確定。

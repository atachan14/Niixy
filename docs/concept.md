# Niixy のコンセプト

Niixy は、人・場所・会話を地図でつなぐソーシャルサービスである。

Account は Room を作成できる。Room と NiiMap は Thread を掲載または共有できる。Thread は一つの開始 ThreadPost から始まり、時系列の返信として育つ。Interface は会話の基礎モデルを変えずに、Account、Room、Thread、ThreadPost に構造化した意味を加える。

NiiMap は Event 掲示板ではない。場所と結びついた Thread を発見・作成する地図上の場である。

サービスは小さな共通モデルを基礎とし、Event、募集、質問、ゲームコミュニティなどの専用体験は将来の Interface で実現する。
